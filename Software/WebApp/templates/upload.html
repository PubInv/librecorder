Upload guidance

Keep specimen organization clean so studies can compare lenses against well-structured inputs.

  • Leave Case ID blank to create a new specimen set.
  • Provide a Case ID to add files to an existing specimen.
  • Select one or more tags to classify the specimen set.
  • Use notes to preserve context alongside the files.
  • Create new tags from the registration page.
  • TIFF microscopy files are supported.
Workflow

Recommended sequence.

  • Upload or append specimen files here.
  • Return to the main workspace.
  • Select the specimen in the left pane.
  • Choose one or more analytical lenses.
  • Run a study and compare outputs.
